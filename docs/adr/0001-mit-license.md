# MIT license

On the Block is public so that strangers can contribute and recruiters can read the code, so we license it under MIT: the most familiar and least restrictive choice, with no barrier to a first PR. The trade-off is accepted knowingly: if On the Block later becomes a product, anyone can fork it commercially. We considered AGPL, which would force hosted forks to publish their changes, but rejected it because it puts some contributors off and the project is portfolio-first for now.
