# On the Block: web app

The Vite + React site for On the Block. It talks to the API set in `VITE_API_BASE` (see `.env.example`).

```bash
npm install
cp .env.example .env
npm run dev      # http://localhost:5273
npm run lint
npm run build
```

Setup for the whole project, workflow and rules are in the root [CONTRIBUTING.md](../CONTRIBUTING.md). How the site fits with the API is in [docs/architecture.md](../docs/architecture.md).
