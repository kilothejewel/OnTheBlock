# On the Block

Discover places in a city and plan a day or night out on a budget. FastAPI backend in `app/`, Vite + React web app in `web/`.

Setup, workflow and project rules for every contributor (human or agent) are in [CONTRIBUTING.md](CONTRIBUTING.md). Use the vocabulary in [GLOSSARY.md](GLOSSARY.md).

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `kilothejewel/OnTheBlock`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
